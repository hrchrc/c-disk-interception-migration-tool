# C盘拦迁器 (C Drive Relocator)

Windows 下的 C 盘空间管理工具。

C 盘空间总是不够用？这个工具可以把 C 盘中占用空间的大目录迁移到其他盘，原位置自动创建符号链接——软件不重装、不感知，照常运行，C 盘空间立刻释放。

## 主要功能

### 目录迁移
- 扫描 C 盘各目录并计算占用空间，按大小排序，一眼看出什么占空间
- 一键迁移到目标盘（D/E 等），复制完成后 C 盘原位置创建符号链接
- 迁移全程软件无感知：不需要卸载重装，原路径依然有效

### 迁移安全
- 内置 Rust 复制引擎：多线程流水线复制，速度比单线程快数倍
- BLAKE3 哈希逐文件校验，迁移后数据完整性与源一致
- 断点续传：中断后继续，不用从头再来
- 迁移前自动检查目标盘剩余空间、路径包含关系等风险

### 还原与修复
- 一键还原：数据搬回 C 盘，删除链接恢复原样
- 链接自动修复：软件更新把符号链接覆盖成真实目录时，自动把新数据合并回目标盘并重建链接
- 删除记录恢复：误删迁移记录可找回

### 开发环境迁移
- 30+ 开发工具的环境变量/配置迁移（Java、Node.js、Python、Go、Docker、Android SDK 等）
- 一键配置、一键还原，迁移后环境变量自动指向新位置
- 配置快照与回滚：变更前自动备份，出问题可回退

### 安装器拦截
- 监控安装程序向 C 盘写入的大目录，写入前拦截确认，从源头阻止 C 盘膨胀
- 监控日志实时显示拦截/迁移/修复记录

### 其他
- 界面：中文
- 环境自检：一键检查管理员权限、引擎、符号链接、目标盘等运行环境
- AI 识别：用大模型识别陌生目录的用途（可选功能，需配置 API Key，支持 13 个国内外平台）
- 基于 MFT 索引的快速扫描：几百万文件秒级完成

## 技术

- **GUI**：Python 3.13 + PySide6
- **复制引擎**：Rust 实现，reader/writer 多线程流水线 + 无缓冲 I/O，支持断点续传（checkpoint 记录 + CRC32 区间校验，中断后从断点继续，损坏数据自动重传）
- **完整性校验**：BLAKE3 逐文件哈希比对
- **快速扫描**：直接解析 NTFS $MFT 构建索引，几百万文件秒级扫描；Cython 加速模块作为 Rust 失败时的兜底路径
- **符号链接**：优先目录符号链接（/D），失败自动降级 junction（/J），再不行用 PowerShell 兜底
- **事务化迁移**：迁移/还原以事务记录方式执行，异常中断后下次启动自动恢复处理
- **AI 识别**：OpenAI 兼容接口，支持 13 个国内外平台，批量识别 + 本地缓存

## 从源码运行

要求：Python 3.13，Windows 10/11

```bash
pip install -r requirements.txt
python src/main.py
```

部分功能需要管理员权限（迁移、符号链接、环境变量操作）。

## 快速上手

1. 启动后自动扫描 C 盘（首次扫描需数秒，基于 MFT 索引）
2. 在"待迁移"列表勾选要迁移的目录，选择目标盘，点"迁移"
3. 迁移完成后，C 盘原位置变成符号链接，软件照常使用

## 注意事项

- 迁移操作会把目录从 C 盘移动到目标盘，请确认目标盘空间充足
- 系统目录（Windows、Program Files 等）有保护，迁移会二次确认
- 迁移后的数据在目标盘，删除 C 盘符号链接**不会**删除目标盘数据
- 符号链接需要管理员权限或开发者模式（软件会自动检测）
- 个别杀毒软件可能对符号链接操作有提示，属正常现象

## 常见问题

**迁移后 C 盘空间没减少多少？**
Windows 系统还原点（卷影副本）会保留文件旧版本，需要清理系统还原点后空间才会完全释放。软件在迁移大量数据后会自动提示。

**软件卸载后，迁移的数据会丢吗？**
不会。数据在目标盘，符号链接只是入口。还原数据：重新装软件或手动把目标盘数据移回 C 盘并删除链接。

**符号链接创建失败？**
需要管理员权限或开启 Windows 开发者模式（设置 → 开发者选项）。

## 构建 Rust 引擎（可选）

源码在 `rust-engine/` 目录。如不使用预编译引擎，可自行构建：

```bash
cd rust-engine
cargo build --release
```

构建产物 `rust-migrate-engine.exe` 放到 `bin/` 目录。
